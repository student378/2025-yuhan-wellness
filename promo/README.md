# 유한대학교 홍보 모션 그래픽

56초 분량의 16:9(1920×1080) 홍보 모션 그래픽입니다.

- `index.html` — 브라우저에서 바로 재생 (외부 의존성: Google Fonts만 사용)
  - `Space` 재생/일시정지 · `←/→` 5초 이동 · `R` 처음부터 · 하단 바로 탐색 · 전체화면 버튼
  - `?render=1` 을 붙이면 컨트롤 UI가 숨겨집니다 (녹화/렌더용)
- `yuhan-promo.mp4` — 위 HTML을 30fps로 프레임 단위 렌더링한 영상

## 영상 다시 렌더링하기

Playwright로 `window.__motion.seek(t)` 를 프레임마다 호출해 스크린샷을 ffmpeg로 인코딩합니다.

```js
await page.goto('file:///.../promo/index.html?render=1');
for (let i = 0; i <= duration * 30; i++) {
  await page.evaluate(v => window.__motion.seek(v), i / 30);
  // page.screenshot() → ffmpeg image2pipe
}
```
